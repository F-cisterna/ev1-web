GuitarShop - Evaluación EV1 Web

Catálogo virtual de guitarras desarrollado como Single Page Application (SPA) para la evaluación EV1-web. El proyecto demuestra la implementación de componentes, enrutamiento y renderizado dinámico de datos.

Enlaces del Proyecto

*   Despliegue en Vercel: https://ev1-4wl25utjk-f-cisternas-projects.vercel.app

Tecnologías y Herramientas Utilizadas

*   React + Vite: Estructura base y empaquetado del proyecto.
*   React Router DOM: Gestión de rutas (Navegación entre Inicio, Desarrollador y manejo de error 404).
*   CSS Modules: Estilos encapsulados utilizando Flexbox, sombras y bordes redondeados.
*   JavaScript (ES6+): Renderizado de listas mediante el método `.map()` y paso de información a través de `props`.

Instalación y Uso Local

Si deseas correr este proyecto de manera local, sigue estos pasos:

1. Clona el repositorio:
   git clone https://github.com/F-cisterna/ev1-web
   
2. Ejecutar
   npm install
   npm run dev
   
y listo.
